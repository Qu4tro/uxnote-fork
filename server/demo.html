Tidewatch
Stations Forecast Pricing

Every tide, from every station you watch

Tidewatch reads the gauges of 3,400 coastal stations and tells you when the water crosses the line you care about.

Alerts

Set a height and a station. Tidewatch sends one message when the water crosses it, and one when it falls back.

History

Ten years of readings per station, charted against the prediction, so you can see where the gauge drifts.

API

One JSON route per station. Ask for a day, a month, or the next high water.
