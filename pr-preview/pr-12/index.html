Widget settings

The widget reads its options from its script tag, once, when the page loads. This page carries them in the query string, so applying a change reloads the page. The notes you have already taken stay where they are.

Two of the options name a server to keep the notes on instead of this browser. A link must not be able to point your notes at somebody else's server, so this page takes a loopback address only: localhost, anything in 127.0.0.0/8, or [::1]. The repo ships server/server.py to run there, with python3 server/server.py --port 8123. The hosted demo is served over HTTPS from github.io and browsers restrict a public page reaching a loopback address (Private Network Access), so the two server options are meant for a demo you run locally and may be blocked here.
